# n8n-nodes-easycompliance

This is an n8n community node for [easycompliance](https://www.easycompliance.de/) – the German SaaS platform for automated sanctions list and PEP screening.

It lets you screen business partners against EU/US/HADDEX sanctions lists and PEP lists directly from your n8n workflows, and it can maintain your daily monitoring list automatically.

[n8n](https://n8n.io/) is a [fair-code licensed](https://docs.n8n.io/reference/license/) workflow automation platform.

## Operations

Both API instances (sanctions lists and PEP) support the same operations:

| Operation | API method | Description |
|---|---|---|
| Check Name | `1` | One-time screening of a single name |
| Check Name and Add to Monitoring | `2` | Screen the name and add it to the daily monitoring list |
| Get Recent Hits | `3` | Hits generated by the daily monitoring within the last 24 hours |
| Get Last List Update | `4` | Date of the last sanctions/PEP list update |
| Remove Name From Monitoring | `5` | Remove an entry from the daily monitoring list (by name or by reference) |

The node normalizes the API responses: screening operations always return `hit` (boolean), `hitCount` and `hits` (array), so an empty result (HTTP 204) does not require special handling in your workflow.

## Credentials

You need an easycompliance account with API access. Customer service provides:

- your **API key**,
- the **sanctions list API URL**, and
- the **PEP API URL** (if your plan includes PEP screening).

All three values are stored in the `easycompliance API` credential. The API key is injected into the POST body of every request (field `api_key`) – it never appears in your workflow JSON.

## Compatibility

- Requires n8n 1.x.
- Requires the easycompliance API with JSON request body support (available since July 2026).
- Node.js >= 20.15 for building.

## Installation

Follow the [installation guide for community nodes](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n documentation. On self-hosted instances: **Settings → Community Nodes → Install** and enter `n8n-nodes-easycompliance`.
